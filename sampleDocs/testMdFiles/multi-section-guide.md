# Developer Guide

## Overview

Acme Portal gives new joiners one place to find accounts, tools and checklists.

## Tooling

Install Java 17 and Maven before you build. Other tools are optional.

## Languages

Teams write services in Java and Kotlin. Scripts are written in Python. Pick the language that fits the job.

## Deployment

The container listens on port 8080. Put the load balancer in front of it.

## Support

For help, email support@acme.example and include the build number.
